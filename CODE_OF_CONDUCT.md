# Code of Conduct

This project follows the **Contributor Covenant, version 2.1**. The full text is available at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project (issues, pull requests, discussions), you agree to follow it.

## Reporting

Report unacceptable behavior to the maintainers through GitHub: use a private channel such as a [private security advisory](https://github.com/philppplik/zero-prompter/security/advisories/new) or contact the repository owner via their GitHub profile. Do not post reports publicly. A dedicated contact address has not been set up yet.

## Enforcement

Maintainers are responsible for clarifying and enforcing these standards and may remove, edit or reject contributions, or ban contributors, for behavior they deem inappropriate, as described in the Contributor Covenant enforcement guidelines.
